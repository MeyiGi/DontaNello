# 0001: Модульный монолит с портами и адаптерами

Дата: 2026-09-28. Статус: принято.

## Контекст

Ассистент предназначен для многолетнего расширения, новых интеграций и независимых автоматизаций. Пользователь требует SOLID, DRY, KISS, понятную иерархию файлов и возможность перехода к микросервисам. Исходный watcher объединял бизнес-правила, API, JSON, CLI и бесконечный цикл.

## Решение

Python-пакет в src/dontanello; возможности в modules; порты принадлежат потребителю. Адаптеры скрывают API и состояние. Bootstrap собирает зависимости. Entrypoints управляют запуском. Инфраструктурные каталоги отделены от функций. Completion переносится первым без изменения ключей JSON, конфигурации чекбоксов или правил дат.

Границы импортов закреплены тестами. Ruff проверяет стиль и ошибки; mypy проверяет типы пакета. Runtime использует стандартную библиотеку. Будущие зависимости допустимы при конкретной пользе.

## Альтернативы

- Продолжать расширять корневой скрипт: смешивает причины изменения и усложняет независимое тестирование.
- Сразу микросервисы: добавляет сетевую доставку, эксплуатацию, версии контрактов и миграции до появления соответствующей потребности.
- Универсальная платформа плагинов: преждевременно фиксирует абстракции неизвестных будущих функций.

## Последствия

Новая функция имеет собственный модуль и явные зависимости. Бизнес-правила тестируются без сети. Появляется больше небольших файлов, зато каждое место имеет понятную ответственность. Выделение сервиса остаётся отдельной работой: интерфейс понадобится адаптировать к сетевым ошибкам и независимому хранению.

JSON и одиночный процесс сохраняют ограничения текущего watcher. Изоляция ошибок источников реализована, но медленный сетевой запрос ещё может задержать очередной источник; независимые исполнители добавляются при появлении длительных задач.
